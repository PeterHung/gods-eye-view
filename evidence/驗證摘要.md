## 部署版的服務設定入口

右下角「設定服務」在本機與部署版本都會保留。可存取本機設定 API 時可以編輯金鑰；若 API 不存在、被拒絕、逾時或回傳登入頁，面板會列出服務、環境變數及設定方式，不顯示金鑰輸入或儲存按鈕，也不推測目前是否已配置金鑰。所有金鑰已配置時仍可重新開啟設定。

設定 API 會相對於目前頁面目錄請求；例如 `/gods-eye/` 對應 `/gods-eye/api/setup/status`。反向代理需要保留相應路由。這項修改沒有解除上游對外部網站／代理請求寫入本機金鑰的限制；部署主機的金鑰仍需由網站管理者設定。
